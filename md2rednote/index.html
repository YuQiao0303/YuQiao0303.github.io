导出与排版配置

页面尺寸

默认开启：一次 Enter 换行，两次 Enter 空一行，三次空两行，依此类推。段落附加间距默认 0 行，设置为 0.5 就额外增加半行（跟随字号与行高）。关闭可恢复标准 Markdown 的空行合并规则。代码块原样保留。

公式分隔符 · 可分别开关

还支持复制时出现的双反斜杠分隔符。关闭某类分隔符后，该类符号按普通 Markdown 处理。代码块和行内代码不会被解析为公式。

粘贴选项

默认开启。网页、Word、ChatGPT 等富文本尽可能保留标题、加粗、列表、链接、代码、表格。普通纯文本或 Markdown 不会自动改写。外部图片需要可访问的 URL；复杂格式建议检查转换效果。

表格列宽

粘贴包含表格的 Markdown 后，可在预览中拖动列分隔线。

列宽修改会自动保存；表格拆页后沿用相同列宽。编辑表格结构后如不合适，可重置。

导出图片

Chrome / Edge 支持选择保存文件夹；其他浏览器会尝试逐张下载。
